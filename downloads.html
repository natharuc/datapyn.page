From source

Development requires Node.js 22, Rust 1.90+, Python 3.12+, uv, and your platform’s native dependencies.

git clone https://github.com/natharuc/datapyn.git
cd datapyn
uv sync --dev --frozen
npm --prefix desktop ci
npm --prefix desktop run desktop:dev
