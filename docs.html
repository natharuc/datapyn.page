Introduction

DataPyn is a desktop IDE built with Tauri for SQL and Python analysis in the same session.

Pynia is the AI built into DataPyn.

SQL and Python blocks in one file.

Installation

All downloads · Tauri releases

Choose the Tauri channel with tags tauri-vX.Y.Z. Python and the analysis libraries are bundled.

Windows

Windows x64: choose the Tauri Setup.exe or portable ZIP. Setup includes WebView2 and prepares the SQL Server ODBC driver.

Linux

Linux x64, Ubuntu 22.04+: choose DEB, AppImage, or tar.gz. SQL Server requires unixODBC and the Microsoft ODBC driver. AppImage supports extract-and-run when FUSE is unavailable.

macOS

macOS 14+, Apple Silicon: download the Tauri DMG and copy DataPyn Tauri to Applications. The current distribution may require permission in Privacy & Security.

Updates

Windows, Linux, and macOS use the signed Tauri update channel. When an update is ready, save your work and install it from the app.

From source

For contributors: Node.js 22, Rust 1.90+, Python 3.12+, uv, and the native dependencies documented in the repository.

git clone https://github.com/natharuc/datapyn.git
cd datapyn
uv sync --dev --frozen
npm --prefix desktop ci
npm --prefix desktop run desktop:dev
