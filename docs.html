Introduction

DataPyn is an IDE for people who work with data every day.

Pynia is the AI built into DataPyn.

Mixed blocks

SQL and Python blocks in one file.

Per-block connections

Each SQL block can use a different connection.

Monaco + offline SQL

Schema-aware editing, cross-database refs.

Installation

All downloads · All releases

Windows

Download DataPyn-Setup.exe from the downloads page. Python is bundled.

Linux

Ubuntu/Debian: install the .deb. Other distros: extract the tar.gz. SQL Server via pyodbc needs unixodbc; pymssql does not.

macOS

Apple Silicon DMG (unsigned). After copying to Applications, right-click Open or run xattr -cr /Applications/DataPyn.app.

From source

For contributors (Python 3.12+, uv):

git clone https://github.com/natharuc/datapyn.git
cd datapyn
uv sync
uv run python source/main.py
